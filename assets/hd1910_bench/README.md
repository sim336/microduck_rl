## 1. 台架整体布局

```
          垂直安装板（78×78×6 mm，立在桌上）
              │
      ┌───────┼───────┐   ← 4×M3 螺丝贯穿（板 + 舵机，背面螺母锁紧）
      │  舵机背面贴板   │
      │  ┌─────┐       │
      │  │HD- │ 输出轴  │ → 25T 摇臂 / 打印摆臂（水平，垂直平面内摆动 ±110°）
      │  │1910│ (水平)  │
      │  └─────┘       │
      └───────┬───────┘
        桌脚（14 mm 高）  ← 放在桌面，板垂直
```

- 板在垂直平面，舵机背面贴板，输出轴**水平**伸出
- 摆臂绕输出轴在**垂直平面**内摆动（像钟摆），0° 时垂直向下
- 配重挂在摆臂末端

## 2. 所需物料（BOM）

| # | 物料 | 规格 | 用途 |
|---|---|---|---|
| 1 | 固定座 | `hd1910_bench_mount.stl`（PETG/ABS） | 立板 + 桌脚 |
| 2 | 摆臂 | `hd1910_bench_arm.stl`（PETG） | 120 mm 摆臂 |
| 3 | 配重盘 | `hd1910_bench_weight.stl` + **钢垫圈** | 0.1/0.3/0.6 kg |
| 4 | 螺丝 ×4 | M3×25 盘头（+垫圈） | 固定舵机到板（安装孔 Ø3.0，非组装孔） |
| 5 | 螺母 ×4 | M3 | 板背面锁紧 |
| 6 | 紧定螺丝 ×1 | M3×6（或自攻） | 锁摆臂到 25T 轴 |
| 7 | 螺杆 ×1 | M8×60 | 配重杆 |
| 8 | 螺母 ×2 + 垫圈若干 | M8 | 固定配重盘 |
| 9 | 舵机 | HD-1910-C001 ×1（专用，不拆真机） | 被测对象 |
| 10 | USB-TTL 半双工适配器 + 稳压电源 | Feetech 兼容 / 0-10V≥3A | 采集 |

> 配重方案：钢垫圈 Ø40×5 mm ≈ 47 g/片。0.1 kg ≈ 2 片 + 调，0.3 kg ≈ 6 片，
> 0.6 kg ≈ 13 片。精确称量后用 M8 螺杆串在摆臂末端孔上，螺母锁紧。

## 3. 装配步骤

### 3.1 固定座
1. 打印 `hd1910_bench_mount.stl`，检查 4 个 M3 孔 + 中心 Ø14 孔贯通、无拉丝
2. 板放桌面，桌脚朝下，板垂直（用直角尺确认）

### 3.2 装舵机
1. 舵机**背面**（无轴的一面，z=-23 面）贴板
2. 对齐 4 个安装孔（板孔位与舵机孔位应重合）
3. 4×M3 螺丝**从舵机正面（有输出轴的一面）穿入**：穿过舵机孔 → 穿过板
4. 板背面用 M3 螺母锁紧（螺丝头在正面四角，不挡摆臂）
5. **核对**：输出轴应从舵机正面伸出、水平朝外、可自由旋转

### 3.3 装摆臂（连接层次：舵机轴 → 摆臂 → M8 配重杆）

摆臂根部是 **Ø36 适配盘**，上面有**两组连接孔**（程序化验证过全部贯通）：

```
              ┌─────────┐
              │  Ø4.95  │  ← 25T 轴孔（毂中心，套舵机花键轴，直接套轴方案）
              │  轴孔    │
  4×M3 摇臂孔 │  ┌───┐  │  ← M3 紧定孔（侧向，锁轴防脱落）
  (Ø28 圆上) ─┤  │ ● │  │
              │  └───┘  │
              └─────────┘
```

**两种连接方式（二选一）：**

- **方案 A（推荐，最稳妥）**：金属摇臂 + 螺丝
  1. 25T 金属摇臂（花键精确、自带紧定）锁到舵机轴上
  2. 打印摆臂的 **4×M3 孔（Ø28 分布圆）** 对到金属摇臂孔上
  3. 4×M3×8 螺丝锁紧（沉头孔已留）
- **方案 B：直接套轴**
  1. 摆臂毂中心 **Ø4.95 轴孔** 套上舵机 25T 花键轴
  2. **M3 紧定螺丝** 从毂侧面锁紧（花键防转、紧定防脱落）
  3. 若孔太紧/太松：用 4.8mm 钻头扩孔 / 锉刀修整

> 注意：M8 只用于摆臂末端挂配重，不是舵机-摆臂连接。

装配后：摆臂垂直向下（q=0），先别锁死，标定后要能松开调零点。
摆臂应能**自由下垂**、手拨能来回摆动（晃动约 5-10 秒自然停下）。

### 3.4 装配重（详见 `hd1910_bench_weight_detail.png`）

固定结构：**M8 螺杆（水平，沿轴方向）穿过摆臂末端配重座的 Ø8.4 孔**，
配重盘串在螺杆上，螺母压紧。

```
  M8螺母+垫圈   M8螺杆（水平）   配重盘（Ø40×5 钢垫圈）    M8端部螺母
  ──●───────┼─────────────┼─────────●───────────●──
        摆臂末端 Ø8.4 孔            堆叠在螺杆上，端部锁紧
```

步骤：
1. **M8 螺杆**（0.6kg 档用 M8×100，0.3kg 档 M8×80，0.1kg 档 M8×60）
   穿过摆臂末端 **Ø8.4 孔**（孔在 z=−120，配重质心正好落在 120mm 处）
2. 摆臂两侧各 **M8 大垫圈 + 螺母**，先固定螺杆位置（不滑动）
3. **配重盘**串在螺杆伸出段（从两侧堆叠），**端部 M8 螺母 + 大垫圈压紧**
4. **称量实际总重**（配重+螺杆+螺母）记录，标定时用实测值；配重质心到
   输出轴距离按实测（设计值 120mm）

**配重物料两个方案：**

| 方案 | 物料 | 0.1 kg | 0.3 kg | 0.6 kg |
|---|---|---|---|---|
| A（推荐） | 钢圆棒切割钻孔（Ø50×20 ≈ 298 g/块） | 1 块+微调垫圈 | 1 块 | 2 块 |
| B | 钢垫圈（Ø40×5 ≈ 47 g/片） | 2 片 | 6 片 | 13 片（需 M8×100，偏长） |

> 方案 B 的 0.6kg 档要 13 片垫圈（65mm），螺杆长、易晃，建议用方案 A 的
> 实心钢块。`hd1910_bench_weight.stl`（Ø40×5）是参考盘/间隔垫，PLA 密度
> 太低不能直接当配重。

### 3.5 检查清单（采集前）
- [ ] 板垂直、舵机固定牢靠、无晃动
- [ ] 输出轴水平，摆臂在垂直平面自由摆动 ±110° 无干涉（摆臂转起来不碰板/螺丝）
- [ ] 配重锁紧（端部螺母压紧、螺杆不滑动），配重中心距轴心 120 mm，实测质量已记录
- [ ] 接线：TTL 半双工 → USB 适配器 → 电脑，稳压电源设定目标电压（6/7.4/8.4 V）
- [ ] 用 Feetech 上位机先跑通：能读位置/速度/电压/温度，能控制转角
- [ ] **核对寄存器表**：`scripts/hd1910_bench_record.py` 顶部的
      `FeetechBus` 寄存器地址（P/D/位置/速度/电压/温度/电流）是否与真机一致

## 4. 采集（真机到位后）

```bash
uv run python scripts/hd1910_bench_record.py \
    --port COM3 --id 1 \
    --mass 0.30 --arm-mass 0.05 --length 0.120 \
    --vin 7.4 --kps 4 8 16 32 --logdir ~/bam_logs/hd1910
```

对每种配置 `{6V, 7.4V, 8.4V} × {0.1, 0.3, 0.6 kg} × {5 轨迹} × {4 档 kp}`
分别跑，共 135 条（同 ST3025 规模）。之后：

```bash
uv run python -m bam.process --raw <raw> --logdir <processed>
uv run --with optuna --with cmaes python -m bam.fit \
    --logdir <processed> --output hd1910 \
    --actuator sts3215 --model m6 \
    --set '{"kt": 0.735, "R": 3.75, "armature": 0.003}' \
    --trials 20000 --workers 4
```

> 详细标定流程见 `src/mjlab_microduck/robot/hd1910_testbench_plan.md`。
