**OpenMicroDuck** 的整机模型，替换官方 microduck_rl 的 Dynamixel XL330 BAM M6 模型。
下文保留首性估算的完整推导链，作为规格书核对与直觉校验的存档。

## 参数推导（6 V 设计点）

直流电机模型（BAM 电压控制律）：堵转时 `τ_stall = kt·V/R`，`I_stall = V/R`。

- **kt = 0.735 N·m/A** —— 直接取自规格书 Kt = 7.5 kg·cm/A（×0.098）。
- **R = 3.75 Ω** —— 6 V / 堵转电流 1.6 A。
  校验：`kt·V/R = 0.735×6/3.75 = 1.176 N·m` = 12 kg·cm ✓（与规格书一致）。
- **armature = 0.0030 kg·m²** —— 反演惯量估计，参考同平台实测：Waveshare
  ST3025（复用 STS3215 控制律）标定 0.00465、BAM STS3215@7.4V 拟合 0.0216
  （台架臂偏重，值偏高）。HD-1910 尺寸小于 ST3025，取 0.0030，fit 范围放宽
  0.002–0.004。需台架复核。
- **摩擦参数（m6）** —— 按 XL330 拟合值按扭矩尺度（1.176/0.52 ≈ 2.26×）缩放
  基座/Stribeck/负载项；`friction_viscous` 已用 6V 运动特性图实测换算（见下节）。
  两项按同平台实测修正：
  - `dtheta_stribeck` **2.9 → 0.4**：2.9 原抄自 XL330（Dynamixel 平台），而同
    平台 Feetech 实测拟合都在 ~0.3：STS3215@7.4V = 0.371、ST3025 = 0.274。
    Stribeck 特征速度改为 0.4 rad/s，更符合 Feetech 平台在低速区的摩擦爬升。
  - `armature` 0.002 → 0.003（见上）。
  **全部摩擦项仍需实测标定。**

## 6V 运动特性图验证（规格书第 11 节）

规格书 A/0 第 6/7 页是 **6V 运动特性图**（PDF 文本层写为「11.6V运动特性图」，实为
「第 11 节 · 6V」，因章节号 11 与「6V」粘连）。图为内嵌位图，已用像素追踪
+ OCR 提取（坐标校准：X=扭矩 0–12 kg·cm，左轴 P(W)/N(rpm)，右轴 I(mA)/效率）。
曲线颜色：**红=P(W)、黑=N(rpm)、黄=I(mA)、蓝=η(%)**。

提取数据（T=4–11 线性段可靠，T<3 有曲线起始伪影）：

|---|---|---|---|

| 1 | 84.3 | 302 | 49.3 |
| 2 | 76.4 | 420 | — |
| 3 | 68.9 | 538 | — |

(*T=0 点受曲线起始绘制影响，取线性段外推。)

**对 BAM 参数的结论：**

1. **R 确认**：外推堵转电流 ≈1.6 A @6V → `R = 6/1.6 = 3.75 Ω` ✓
2. **kt 确认**：堵转点 12 kg·cm / 1.6 A = 7.5 kg·cm/A = `0.735 N·m/A`，与规格书
   Kt 一致 ✓。（电流-扭矩斜率 117.6 mA/kg·cm 给出 8.50 kg·cm/A 的增量 kt，比
   堵转点略高——这是 BAM `load_friction_*` 项吸收的负载摩擦，非电磁常数。）
3. **空载转速确认**：黑线外推 T→0 得 ~92 rpm = 规格表 6V 空载 92 RPM ✓
4. **friction_viscous 实测换算**：空载电流 184 mA（黄线 T=0 截距）在空载转速
   9.634 rad/s 时 `kt·I_nl = friction_base + viscous·ω`：
   `0.735×0.184 = 0.0095 + viscous×9.634` → `friction_viscous ≈ 0.013 N·m·s/rad`
   （原 XL330 缩放估计 0.0107 → 修正为 0.013，**已写入 hd1910_m6.json**）

**图中无法得到的**：Stribeck 项、负载相关摩擦、`error_gain`/`kp_fw`（控制律参数）
——仍需台架（testbench）标定。

## 控制律骨架（复用 xl330）

`hd1910_m6.json` 的 `"actuator": "xl330"` 复用 XL330 的电压控制律骨架：
`duty = Δq × kp_fw × error_gain`（error_gain 基于 4096 counts/rev 编码器，
与 HD-1910 12-bit 编码一致）。`max_current = 1.75 A`（HD-1910 堵转电流
1.2–2.0 A 的合理连续上限）。

**待台架标定项：**
1. `error_gain`（固件 KP→PWM 换算）——需示波器实测
2. `kp_fw`（固件 P 增益）——当前取项目既有值 200
3. `max_current`——当前取 1.75 A
4. 全部摩擦参数（friction_* / dtheta_stribeck / alpha）
5. `armature` 反演惯量

## 接线方式

`microduck_constants.py` 中 `USE_HD1910 = True` 启用 HD-1910 模型（默认）。
置 `False` 恢复官方 XL330 模型用于 A/B 对照。

## 训练注意

- BAM 的 `edit_spec` 会按 `max(vin_range)×kt/R` 重写 `forcerange`
  （HD-1910: 8.4×0.735/3.75 ≈ **±1.65 N·m** 安全上限），无需改 MJCF
  `chosen_actuator` 的 ±0.96（仅非 BAM 回退路径使用）。
- 关节角度限位、HOME 姿态、观测/动作契约（obs 61 → act 14）与官方一致，
  换执行器只改 `microduck_constants.py` 一处。
